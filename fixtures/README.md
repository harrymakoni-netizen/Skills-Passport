# Fixtures

Offline sample data for the WhatsApp simulator (`/dev/chat`), seed data and tests.

- `photos/` — drawn illustrations of finished work in the five pilot trades, with photographic grain. They are
  fictional and licence-free, generated by `pnpm --filter @sp/adapters fixtures`. For a live pitch, replace them
  with real artisans' photos taken with consent.
  - `duplicate-solar-roof-resized.jpg` is a resized, recompressed copy of `solar-roof-after.jpg` for the
    duplicate-image fraud rule.
  - `too-dark-inverter.jpg` triggers the "please retake" prompt.
- `audio/` — short WAV voice notes. Their spoken content is irrelevant offline: the mock speech-to-text returns
  the fixture transcript for the job type (see `packages/adapters/src/fixtures.ts`).
